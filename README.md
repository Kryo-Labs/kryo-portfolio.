# KRYO — Portfólio

Portfólio de desenvolvimento com visual escuro, minimalista e responsivo.
Implementado com HTML, CSS e JavaScript, sem dependências externas.

## Visualização local

Abra `index.html` no navegador ou utilize um servidor estático de sua preferência.
Não há etapa de instalação ou compilação.

## Estrutura

- `index.html`: conteúdo, navegação e seções do portfólio.
- `css/style.css`: identidade visual e layout responsivo.
- `js/script.js`: reservado para futuras interações.
- `assets/images/`: reservado para imagens públicas dos projetos.

## Conteúdo

A seção Projetos apresenta Assistente Inteligente para Android e Sistema de
Sobrevivência e Simulação. Imagens e links poderão ser adicionados futuramente.
As seções Sobre e Contato ainda possuem conteúdo provisório.

## Cuidados antes de publicar

Utilize apenas informações e materiais autorizados para divulgação pública.
Não inclua credenciais, arquivos de ambiente ou dados privados.
O `.gitignore` exclui dependências, arquivos gerados e arquivos locais comuns;
a revisão do conteúdo continua necessária a cada envio.
